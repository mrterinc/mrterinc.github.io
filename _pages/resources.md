<strong>_Regulatory Comment Trackers_</strong>

**SEC Regulation Crypto Assets - Comment-Letter Tracker (File No. S7-2026-27)**

In August 2026 the SEC proposed Regulation Crypto Assets, which would create two exemptions allowing crypto assets to be sold to the public without registering the offering, a procedure for bringing the resulting securities-law obligations to an end, and preemption of State registration requirements. This tracker archives every comment letter as it arrives and codes it on two axes: its stance on each provision the Commission proposed, and the direction it would move that provision. The second axis is there because on this file letters that read as opposition ask for opposite things, some for fewer constraints and some for more. The site also records which of the Commission's 154 numbered questions have been answered, and which of the alternatives the release considered and declined commenters have asked it to revisit. Every provision is read by three raters and every split vote is shown. The comment period closes 20 October 2026.
